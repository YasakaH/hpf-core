# Operational Validation Quality Gates

## Phase Exit Criteria

### Coverage
- [ ] Every lifecycle stage exercised at least once
- [ ] All behavioural stages: Understand, Plan, Validate, Execute, Verify, Reflect

### Persona Diversity
- [ ] All planned personas evaluated
- [ ] Current: Principal Engineer, Staff Engineer, Product Manager, UX Designer, Security Engineer

### Scenario Diversity
- [ ] Multiple task types represented
- [ ] Engineering: architecture, implementation, optimization
- [ ] Product: prioritisation, roadmapping, stakeholder alignment
- [ ] Design: user research, usability testing, accessibility
- [ ] Security: threat modeling, compliance, review

### Evidence Quality
- [ ] Validation logs completed for every evaluation
- [ ] Logs contain observations, not just empty templates
- [ ] Friction points documented
- [ ] Performance bottlenecks recorded

### Pattern Confidence
- [ ] Recurring findings observed across multiple evaluations
- [ ] Classification using review taxonomy (architecture, behaviour, evidence, usability)
- [ ] Findings grouped by persona type
